# Projects: creating, opening, switching

Everything Magpie remembers — your titles, tags, folder list, and
smart collections — lives in one **project file** on disk. A project
is just a single file with the `.magpie` extension. You choose where
it lives (your Documents folder, an external drive, wherever) and
what to call it (`FamilyPhotos.magpie`, `Work-Receipts.magpie`, …).

Magpie can only have one project open at a time, so switching
projects is like closing one photo album and opening another.

## Your very first project

The first time you launch Magpie you'll see two buttons in the middle
of the window:

- **New Project…** — create a brand-new empty project.
- **Open Project…** — open a `.magpie` file that already exists.

Pick **New Project**, choose where to save it (for example
`Documents\Photos\Family.magpie`), and Magpie is ready. From then on
that same project re-opens automatically every time you launch Magpie.

> **Upgrading from an earlier version?** If Magpie already had data
> from before projects existed, that data is preserved as
> `Default.magpie` inside your Windows AppData folder and listed under
> **Recent projects** on the welcome screen the first time you launch
> the new version. Magpie won't open it for you — click it once and
> then, if you like, use **Project → Save Project As…** to move it
> somewhere you'll remember.

## Opening a project by double-clicking

`.magpie` files show the Magpie icon in Windows Explorer, and
double-clicking one opens it directly in Magpie. If Magpie is already
running with a different project open, that instance switches to the
one you double-clicked.

## The Project menu

Everything project-related is in the **Project** menu on the menu
bar:

| Menu item              | What it does                                         |
| ---------------------- | ---------------------------------------------------- |
| **New Project…**       | Pick a location for a fresh empty project.           |
| **Open Project…**      | Open a project file that already exists.             |
| **Save Project**       | (Nothing to do — Magpie saves as you type.)          |
| **Save Project As…**   | Copy the current project to a new file and switch to it. |
| **Close Project**      | Close the current project. Magpie returns to the welcome screen. |
| **Exit**               | Quit the app.                                        |

The last-used project reopens on the next launch, provided you had a
project open when you quit. If you'd rather have Magpie start on the
welcome screen, close the project (Project → Close Project) before
quitting.

## Recent projects

The welcome screen shows the most recent projects you've opened, in
order. Click one to open it — no dialog needed.

## Multiple projects: when to use them

Keep everything in one project unless you have a strong reason to
split. Some good reasons:

- **Different audiences.** A "personal photos" project on your laptop
  and a separate "wedding shoot" project on a work drive.
- **Different lifespans.** Long-lived family photos in one place; a
  short-term project (e.g. renovation documentation) in another that
  you'll archive when done.
- **Different backup strategies.** Store one project on a synced
  cloud folder and another on a local-only drive.

Since projects are just files, you can back one up by copying the
`.magpie` file somewhere safe, share it by emailing the file, or
archive it by moving it into a `.zip`.

## Where the file actually is

Wherever you put it. If you forgot, the current project's location is
shown in the top bar next to the project name; hover over it to see
the full path. **Project → Save Project As…** copies it wherever you
like.
