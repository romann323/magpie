# Keyboard shortcuts

You can do everything in Magpie with a mouse, but keyboard shortcuts
make the whole thing much faster once you know them.

## Projects

| Shortcut               | What it does                            |
| ---------------------- | --------------------------------------- |
| **Ctrl + N**           | New Project…                            |
| **Ctrl + O**           | Open Project…                           |
| **Ctrl + S**           | Save Project (a no-op — Magpie auto-saves) |
| **Ctrl + Shift + S**   | Save Project As…                        |
| **Alt + F4**           | Quit Magpie                             |

## Editing

| Shortcut          | What it does                                   |
| ----------------- | ---------------------------------------------- |
| **Ctrl + Z**      | Undo the last title / tag / rename change      |
| **Ctrl + Y**      | Redo                                           |

The Undo / Redo history is per session — it clears when you close the
project or quit the app.

## Magnifier

| Shortcut          | What it does                                   |
| ----------------- | ---------------------------------------------- |
| **F11**           | Open the currently-selected file in the magnifier |
| **Double-click**  | Same as F11 on the file you double-clicked      |
| **← / ↑**         | Previous file (inside the magnifier)            |
| **→ / ↓**         | Next file                                       |
| **Esc**           | Close the magnifier                             |

## Picking files

| Shortcut                       | What it does                                    |
| ------------------------------ | ----------------------------------------------- |
| **Click**                      | Pick one file                                   |
| **Ctrl + Click**               | Add or remove one file from your selection      |
| **Shift + Click**              | Pick everything between the last click and this one |
| **Esc**                        | Unpick everything                               |

## Everyday actions

| Shortcut                       | What it does                                    |
| ------------------------------ | ----------------------------------------------- |
| **Delete**                     | Send the selected files to the Recycle Bin      |
| **Backspace** (empty search)   | Remove the rightmost tag chip                   |

## Titles and tags

| Shortcut                       | What it does                                    |
| ------------------------------ | ----------------------------------------------- |
| **Enter** (in the title)       | Save what you typed                             |
| **Enter** (in the filename)    | Rename the file on disk                         |
| **Esc** (in the filename)      | Revert to the previous filename                 |
| **Enter** (in the tag box)     | Save the tag you just typed                     |
| **Space** (in the tag box)     | Save the tag you just typed                     |
| **Comma** (in the tag box)     | Save the tag you just typed                     |
| **Backspace** (empty tag box)  | Remove the last tag you added                   |
